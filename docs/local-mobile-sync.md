# 本地博客与手机任务同步

本地开发先行，云服务器后接入。手机使用 Expo Go，博客提供同一 ACTION 数据源。实验离线模式的数据单独保留，不自动上传。

## 启动与连接

在博客根目录先执行 `npm run mobile:prepare`（迁移前自动备份 SQLite 并校验），再执行 `npm run dev:lan`。默认联调端口 **3002**，不占用原有博客的 3000 端口。

Windows 也可执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local-mobile.ps1`。脚本检查并启动缺失的博客/Expo 服务，在 `.local-mobile/` 保存日志；已有同端口服务不会被停止。启动前须已安装两端依赖并生成 Prisma 客户端。

1. 电脑访问 `http://127.0.0.1:3002/workspace/settings`，使用现有博客所有者账号登录。
2. “手机任务看板”中点击“生成手机配对码”；8 位码仅使用一次，5 分钟内有效。新码使旧码失效。
3. 手机和电脑连接同一可信 Wi-Fi。在 Expo Go 输入 `exp://电脑局域网IP:8082`。
4. App 顶部选择“连接博客”，服务地址填写 `http://电脑局域网IP:3002`，输入配对码。
5. 手机新建任务，电脑“行动”页刷新或等待约 15 秒即可看到；电脑修改后在手机点击“刷新任务”。

当前电脑局域网地址曾检测为 `192.168.31.93`；网络切换后以启动脚本实际输出为准。手机地址不能填写 `127.0.0.1`。电脑休眠、关机或手机离开局域网后，实时同步暂不可用。

若手机打不开服务地址，先检查电脑日志、同一 Wi-Fi、访客网络的设备隔离和 Windows 防火墙。本次实现未自动放开防火墙，也未配置路由器端口转发。

## 行为与数据保护

- 手机只读写行动的标题、优先级、估时、状态及回收站删除；不开放财务、正文、附件或其他记录接口。现有正文、关联、标签、项目/课程关系和重复行动语义保留。
- 支持待办、进行中、等待、受阻、已完成五种状态。旧任务估时为空，显示“未估时”，不会假填 0；手机新任务估时必须为正整数。
- 完成数、预计总时长和未估时数量基于全部未归档、未删除行动，不随手机筛选变化。
- 第一版在线优先，断网只读最近快照，不排队上传离线编辑。失败保留输入；版本冲突需刷新核对后重新编辑。新增重试使用同一标识，避免重复任务。
- 手机连接有效 7 天；令牌存于原生 SecureStore，服务端只存哈希。电脑设置页可撤销连接。网页 Cookie 和 Origin 防护仍有效，手机令牌不能登录整个工作台。
- 开发 HTTP 仅允许显式启用的可信内网；正式手机版本只接受 HTTPS。缓存含任务标题等私密信息，保存在 App 本地；断开时清除当前连接缓存。
- “实验离线”与“连接博客”共存，原手机任务仍留在离线模式。本次不自动导入历史任务。
- 浏览器版用于离线看板预览；原生连接请在 Expo Go 验收，未开放浏览器跨域配对。

## 后续云端接入

将博客部署为 HTTPS 单实例服务，持久保存 SQLite 和附件目录，迁移并校验数据后，在手机重新配对新域名。云端不得开启开发用 HTTP 例外。完成公网部署后才验收流量、不同 Wi-Fi 和电脑关机后的访问。
