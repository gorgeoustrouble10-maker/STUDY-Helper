# AI 助手使用指南

工作台内置的可选 AI 助手：基于现有业务层与 SQLite 操作记录，助手只能通过封闭的业务工具读写你的数据，所有写入受审批、幂等与审计约束。本指南面向日常使用；运行配置见 `.env.example`，验收证据见 [ACCEPTANCE.md](./ACCEPTANCE.md)。

## 一、启用与关闭

助手默认关闭。在项目根目录 `.env` 中配置后重启生产服务器（`npm run build` 后 `npm start`）生效：

```powershell
AI_ENABLED=true
AI_PROVIDER=deepseek          # deepseek | openai-compatible | ollama
AI_MODEL=deepseek-chat
# AI_BASE_URL=               # 自定义接口地址（ollama 默认 http://127.0.0.1:11434/v1）
# AI_API_KEY=                # deepseek 与 openai-compatible 必填；ollama 本地运行免密钥
```

- 未配置或 `AI_ENABLED` 不是 `true` 时，悬浮按钮整体隐藏，工作台其余功能不受影响。
- `.env` 不进入版本库；更换密钥后重启即可。
- 三种提供商都走 OpenAI 兼容协议，由官方 SDK（`@ai-sdk/deepseek` / `@ai-sdk/openai-compatible`）处理流式与思考字段。

## 二、打开与界面

登录工作台后，右下角的 ✦ 悬浮按钮即是入口。面板包含：

- **对话切换**：下拉选择历史对话或开始新对话；新对话以首条消息为标题。历史保存在服务器数据库，换浏览器登录后仍在。
- **模式切换**：分析模式 / 工作模式（见下节），默认分析模式。
- **消息区**：你的提问、助手的回答与工具卡片（每执行一个操作生成一张卡片，展示结果与后续动作）。
- **输入框**：回车或点「发送」提交；生成中变为「停止」，点击即中断本轮（已生效的写入会保留）。

## 三、两种模式

| 能力 | 分析模式（默认） | 工作模式 |
| --- | --- | --- |
| 搜索、读取记录与概况 | ✅ | ✅ |
| 对现状的分析、建议、解释 | ✅ | ✅ |
| 新增内部记录 / 建公开稿草稿 | ❌ | ✅ 直接保存（有限额，可撤销） |
| 修改已有记录 | ⛳ 仅生成待确认提议 | ⛳ 仅生成待确认提议 |
| 完成/归档等操作、复盘快照 | ⛳ 仅生成待确认提议 | ⛳ 仅生成待确认提议 |

选择建议：想让它「先看看再出主意」用分析模式；想让它「直接帮我记一条」切工作模式。即使在工作模式，除新增外的改动依然必须经你确认。

## 四、助手能做什么（11 个工具）

**只读（6 个）**

| 工具 | 用途 |
| --- | --- |
| 搜索记录 | 按关键词、类型、状态或标签检索，返回摘要 |
| 读取记录 | 读取一条记录的完整字段与正文（长正文分块续读） |
| 今日概览 | 今日重点、到期、逾期、受阻行动与今日收支 |
| 财务汇总 | 本月收支、账户余额与预算消耗（整数分） |
| 标签清单 | 全部标签与使用次数 |
| 公开资料 | 读取你的公开个人资料 |

**写入（5 个）**

| 工具 | 行为 |
| --- | --- |
| 新增记录 | 仅工作模式直接保存，卡片提供「撤销这条新增」 |
| 建公开稿草稿 | 从素材新建独立的公开稿草稿，**绝不发布** |
| 修改提议 | 对已有记录的部分字段改动，展示差异后由你确认 |
| 操作提议 | 完成 / 重新打开 / 归档 / 取消归档 |
| 快照提议 | 为复盘生成关联证据的当时快照 |

## 五、确认、拒绝与撤销

**提议类操作**的卡片会显示改动明细（如「改动：正文、状态」「预期版本 3」）和两个按钮：

- **确认执行**：服务端校验内容哈希与版本后落库。若记录在此期间被你改过，返回 409 冲突，提议保留、不会自动覆盖，你可对照最新内容重新决定。
- **拒绝**：不做任何改动，卡片标记「已拒绝，未改动记录」。

提议 **24 小时**未处理自动过期。确认请求只携带操作 ID、决定与预期哈希，不重发内容正文，避免篡改。

**直接新增的记录**（工作模式）：只要创建后没被修改、没加关联、没发过版本，卡片上的「撤销这条新增」就能把记录移入回收站；一旦你手动编辑过，就只能自己手动处理。

## 六、助手永远不做的事

以下操作没有对应工具，系统提示与代码双重约束，被要求时助手会说明需要你亲自操作：

- 发布、撤回公开稿（草稿除外）
- 删除记录、清空回收站、导入恢复备份
- 合并标签
- 修改公开个人资料

## 七、限额与异常

| 项目 | 限制 |
| --- | --- |
| 单轮模型步数 | 最多 6 步 |
| 单轮工具调用 / 直接新增 | 20 次 / 10 条 |
| 单条消息长度 | 8000 字符 |
| 发送频率 | 每 5 分钟最多 20 轮，超出返回 429 稍后再试 |
| 上下文 | 自动携带当前浏览的记录（最多 5 条摘要）与最近 40 条对话历史 |
| 单轮时限 | 2 分钟，超时自动收敛为失败 |

- **失败表现**：流中断或响应异常时，本轮收敛为失败并提示「生成过程中出现问题，本轮已停止。已确认的操作仍然有效，你可以重试。」不会留下半截回答或半执行的操作；同一轮重复提交会被幂等拦截（409）。
- **供应商错误不外泄**：模型接口的原始报错与密钥不会出现在浏览器中。

## 八、隐私与安全

- 所有 AI 接口都在所有者登录 + 来源校验之后，访客无法触达。
- 你的数据存在本地 SQLite；只有你发送的提问与助手读取的记录内容会经过所选模型服务商的接口。
- 每轮运行、每次工具调用、每个提议（含哈希与前后状态）都写入审计记录，可追溯。

## 九、常见问题

**Q：为什么它改不了我让它改的记录？**
修改一律走提议，需要你在卡片上确认；这是防止模型误操作的设计。确认后立即生效。

**Q：确认时提示冲突（409）怎么办？**
说明这条记录在你提问之后被修改过（可能来自另一个窗口或自动保存）。提议不会丢失：刷新最新内容后，重新描述你的修改意图让它基于新版本再提议一次。

**Q：撤销按钮消失了？**
记录创建后被修改或关联过，出于安全不能自动撤销，请到回收站/编辑页手动处理。

**Q：想换模型或换成本地 ollama？**
改 `.env` 的 `AI_PROVIDER` / `AI_MODEL`（ollama 免密钥，填 `AI_BASE_URL=http://127.0.0.1:11434/v1`），重启生效。

**Q：金额类字段要注意什么？**
所有金额使用整数分（12.50 元 = 1250）。账户不明确时助手会先询问，不会猜。

## 十、给维护者

- 代码位置：工具与限额 `src/lib/ai/tools.ts`、运行编排 `src/lib/ai/run.ts`、提议/决策/撤销 `src/lib/ai/operations.ts`、界面 `src/components/ai-assistant.tsx`、路由 `src/app/api/workspace/ai/[...path]/route.ts`。
- 测试不访问真实供应商：`node scripts/mock-llm.mjs 4510` 启动本地模拟模型，配合 `tests/ai-*.test.ts` 与 E2E（环境变量见 [TESTING.md](./TESTING.md)）。
- 扩展新工具时遵循既有约束：输出不回传密钥与内部错误；写入必须走操作记录与租约校验；发布/删除类能力不开放。
