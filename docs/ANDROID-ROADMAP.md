- 云端网页代码已有 AI 分析/工作模式和工具操作，但初次检查时 `AI_ENABLED=false`，未配置模型和密钥。本轮启用的是移动服务，未改动旧网页的模型配置。
- 旧网页是单用户体系，移动 API 是独立的多用户试用数据库。两者尚未共享账号、业务记录、附件与 AI 历史。当前仅移动端多设备同步成立。

## 数据统一的约束

先把服务器实际部署的源码作为核对对象，不能只依据本地旧快照推断网页功能。保留现有部署和数据库，先完成差异清单及迁移验证。

目标是两端调用同一套按用户授权的业务服务。统一查询、写入、幂等操作与变更日志，AI 工具也调用这套服务；不能把旧网页所有者 Cookie 或全局查询接口直接开放给移动用户。首次迁移需明确旧数据属于哪个已有移动用户，不能按注册顺序或用户名猜测归属。

迁移前做一致性备份，记录用户/记录/关联/附件/历史数量；试运行检查冲突与引用，再切换入口。保留回滚方案，客户端离线队列需在旧协议兼容或完成确认后切换。公开发布继续使用独立快照，避免泄露内部笔记和 AI 上下文。

## 验证与交付方式

每一轮交付可安装 APK、功能差异与待办清单、关键业务测试结果。按用户要求在本机构建，使用 HTTP，不安装到模拟器。构建与接口测试通过不代替真实手机验收；真机体验依据用户安装反馈继续修复。

当前 0.2.0 不要求增加本机依赖；DeepSeek 模型与密钥已配置到服务器私有环境文件。密钥不进入 APK、Git、业务数据或应用日志。
