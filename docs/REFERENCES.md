# 参考与取舍

参考项目的产品模式；没有将其完整代码复制进本项目。实际安装依赖的许可证随npm包分发。依赖已通过 package-lock.json 锁定精确版本。已扫描 node_modules 全部包的 license 字段（2026-10-14）：以 MIT（271 个）、Apache-2.0（28 个）、ISC（29 个）、BSD（8 个）为主；个别包为 MPL-2.0（文件级 copyleft，作为依赖分发不传染）、EPL-2.0（elkjs）、CC-BY-4.0（许可文本类），本项目为本地自用部署、不分发产物，上述许可证均可安全使用。

- AstroPaper / Tailwind Nextjs Starter Blog：阅读排版、文章与作品入口。https://github.com/satnaing/astro-paper / https://github.com/timlrx/tailwind-nextjs-starter-blog
- Ghost / Payload：内容发布、草稿与版本分离。https://github.com/TryGhost/Ghost / https://github.com/payloadcms/payload
- Quartz：持续更新的花园主题与关联阅读。https://github.com/jackyzha0/quartz
- Memos：快速捕获、后续整理。https://github.com/usememos/memos
- SiYuan / Logseq / Trilium / Outline：引用、知识组织、版本和检索。https://github.com/siyuan-note/siyuan / https://github.com/logseq/logseq / https://github.com/TriliumNext/Trilium / https://github.com/outline/outline
- AFFiNE / AppFlowy：不同工作视图共享内容。https://github.com/toeverything/AFFiNE / https://github.com/AppFlowy-IO/AppFlowy
- Vikunja / Plane / Super Productivity：任务状态、重复行动、项目上下文和保存筛选。https://github.com/go-vikunja/vikunja / https://github.com/makeplane/plane / https://github.com/super-productivity/super-productivity
- Karakeep：资源来源与收藏分类。https://github.com/karakeep-app/karakeep
- Actual Budget：财务使用专门结构，精确存储金额。https://github.com/actualbudget/actual
- Homebox：物品、位置和维护。https://github.com/sysadminsmedia/homebox
- Monica：人物与共同经历。https://github.com/monicahq/monica
- Reactive Resume：经历与输出组织；当前提供简历链接和职业发展专题。https://github.com/reactive-resume/reactive-resume

未引入多人协作引擎、无限画布、付费会员、银行同步或完整简历排版引擎。第一版覆盖指定领域的基础记录、关联和操作。

可用性：清楚的保存反馈、错误恢复、渐进显示专门字段与键盘操作。权限参考OWASP默认拒绝与逐请求校验。https://www.nngroup.com/articles/ten-usability-heuristics/ / https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html
